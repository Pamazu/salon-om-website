# SectionHeading

The eyebrow, serif title, gold hairline ornament and optional lead that open every section.

- **Provide:** `title`, optional `eyebrow`, `lead`, `align` (`start` | `center`), `size` (`large` for landing sections), `as` (heading level, `h2` default).
- The eyebrow is one or two words naming the section ("Coaching", "My story"). The title is a short, warm phrase, not a label.
- Centre it only above centred content (testimonials, CTA, affirmation rows).
