# NewsletterForm

An email sign-up band: title and one line on the left, the field and Subscribe on the right. It validates, shows a sending state and thanks the person.

- **Provide:** optional `eyebrow`, `title`, `text`, `buttonLabel`, `tone` (`linen` | `forest`), and `onSubmit(email)`, which may return a Promise. Connect it to the chosen email tool.
- Say what people will get and how often. Never promise anything Salon OM doesn't send.
