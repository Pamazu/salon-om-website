# Affirmation

A tile of colour or texture holding one short phrase in italic Cormorant: the "Feel it to heal it" tiles from the mood board.

- **Provide:** `text` (2–8 words), optional `attribution`, `tone` (`sand` default, `linen`, `stone`, `surface`; `sage` sparingly), `image` (a light photo or texture; a `photo-veil` wash keeps the `ink` text legible in both themes).
- Lay three side by side in `.om-row` inside a full-bleed `Section` (`width: 'bleed'`, `flush`). On mobile the row scrolls sideways with snap points, so each tile keeps its size.
- Use them as a pause between denser sections, once per page. Never more than one sentence in a tile.
