# Hero

The opening of a page: eyebrow, large Cormorant headline, lead, up to two actions and a footnote, beside an arched media window.

- **Provide:** `title`, optional `eyebrow`, `lead`, `primary`, `secondary` (`{label, href}`), `footnote` (a node under the actions, such as `WaveSound`), and either `media` (any node inside the arch, such as `Shoreline`) or `image` + `imageAlt`.
- **Desktop:** text left, arch right (max 480px wide). **Tablet:** the same two columns, tighter. **Mobile:** text first, the primary button full width, the arch below (max 380px).
- Keep the headline to 2–6 words in the brand voice. The lead is one sentence.
