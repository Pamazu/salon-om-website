# Logo

The full Salon OM mark (ring, SALON, Om and its flourish), drawn inline so it takes any brand ink. There is no separate monogram.

- **Provide:** `size` (width in px) or `height`, `tone` (`gold` default, `ink`, `ivory`, or `current` to inherit text colour), and optionally `cut`.
- **Cuts:** `master` is the artwork as drawn, for 240px wide and up. `small` has heavier hairlines and a larger SALON so the ring, lettering and tail survive at header sizes. When you give `size`, the component chooses the cut for you. When you size it with CSS, pass `cut: 'small'` below 240px.
- Sizes in use: header 128px tall (desktop) / 104 (tablet) / 84 (mobile), 84 / 76 / 64 when the header compacts on scroll, footer 150 / 120px, CTA band 120 / 96px.
- Leave clear space around the mark of at least the height of the "m".
- **Don't:** crop it down to "Om", stretch it, add shadows or outlines, set it on busy photography, or recolour it outside `gold`, `ink`, `ivory`.
