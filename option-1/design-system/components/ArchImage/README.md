# ArchImage

A photograph with an arched top, the arched-alcove motif from the spa interiors on the mood boards. Without an image it shows a tinted placeholder slot.

- **Provide:** `src` + `alt`, or `tone` + `label` for a placeholder. Optional `shape` (`arch` | `square`), `ratio` (CSS aspect-ratio, default `3 / 4`), `caption`.
- Use photography that is warm, natural-light, textured and quiet: sand, water, leaves, stone, hands, linen. Never use stock smiles or saturated colour.
- Use one arch per view. Repeating arches make the motif lose its calm.
