# CTABand

The closing invitation of a page: the logo (small cut), an eyebrow, a title, one line and a button, centred on a neutral band.

- **Provide:** `title`, optional `eyebrow`, `text`, `action` (`{label, href}`), `extra` (a node beside the button), `tone` (`sand` default, `linen`, or `forest`), `logo: false`.
- Keep it neutral (`sand` or `linen`). `forest` exists for a single, deliberate accent moment and should stay rare. A full-width saturated band breaks the colour proportions.
- Use one per page, just before the newsletter or footer. The title is an invitation, not a command ("Ready to choose growth?").
