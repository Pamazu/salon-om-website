# Button

One clear action, set in spaced uppercase Jost.

- **Provide:** `children` (label), optional `href` (renders a link), `variant`, `size`.
- `primary` (gold-ink fill) is for the main action of a view, usually "Book a session". Use it at most once per section.
- `outline` is for a secondary action that sits beside a primary one. `text` (gold-ink with an arrow) is for "read more" style links inside cards and heroes.
- `light` is only for dark bands (`CTABand`, forest sections).
- Labels: 1–3 words, verb first, written in sentence case in code (CSS uppercases them): "Book a session", "Read my story".
