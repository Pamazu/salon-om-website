# Button

A pill button in small tracked caps, with an optional arrow that nudges on hover. Every state change eases in and out (0.6s).

- **Provide:** `children` (sentence case; the CSS uppercases it), `href` or `onClick`, and `variant`:
  - `primary` (default): forest fill, ivory text (5.5:1). The main action everywhere except on the hero film.
  - `light`: ivory fill, ink text. The main action on film (hero, closing film).
  - `ghost`: glass with an ivory outline. The second action on film and photos.
  - `ink`: ink fill on clay (form submit).
  - `line`: ink outline on clay.
- `size="small"` for tiles and the header. `arrow` adds the arrow.
- One primary action per screen.
