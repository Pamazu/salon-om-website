# Manifesto

The brand idea on clay. When it starts with OM, **OM sounds first, alone**: its letters drift together out of a soft blur, a faint glow swells like a hum, and after a held pause the rest is **written in letter by letter**: each letter clears from a blur and rises into place (1.5s each, 20ms apart). Accent words are set in Light Italic, forest-deep. Two thin rings draw themselves behind the text and then breathe slowly.

- **Provide:** `text`, `accents` (exact words, punctuation included, e.g. `everything.`), `eyebrow`.
- Keep it to two or three sentences (under ~130 letters) so the whole piece settles within about 7 seconds.
- Plays again each time the slide is reached.
