# Logos

The Option 2 v2 mark as vector files: **SALON above a lean OM** (stacked), **SALON | OM** (inline) and OM alone, each in ivory, umber and forest, plus the favicon (OM small cut, forest).

- Stacked: hero and footer, 200px wide or more. Inline: header, 24-30px tall. OM: favicon and tiny marks.
- Ivory on dark and film, umber on clay, forest for a single accent use.
- Outlined from Cormorant Garamond (SIL OFL): OM in Light 300 (master) or Regular 400 (small cut), SALON in Medium/SemiBold. The O is opened to a true circle.
