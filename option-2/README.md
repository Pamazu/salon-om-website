# Salon OM — Option 2 ("OM is everything."), v2

Open **site/index.html** in a browser (Chrome or Safari) to see the homepage. Keep the folder together: the page loads its films, fonts and photos from the folders next to it.

- `site/` — the homepage: a full-screen slideshow through the five elements, with slow-motion looping films.
- `shared.md` — rules and facts (read first). `design.md` — design decisions, layout and the **motion rules**. `specs.md` — what is done and what is pending.
- `design-system/` — a copy of the "Salon OM Option 2" design system (tokens, components, logos as code, docs).
- `site/brand/` — the v2 logo as SVG: stacked (SALON above OM), inline (SALON | OM) and OM, in ivory, umber and forest.
- `media/raw/` — the original films from Magnific.
- `source/` — the build scripts (page, logo, film encoding, design system).

Tip: macOS "Reduce motion" (System Settings → Accessibility → Display) makes the page play its gentler motion. Turn it off to see the full choreography.
