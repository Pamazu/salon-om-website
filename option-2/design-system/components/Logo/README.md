# Logo

The Option 2 mark. The brand is registered as SALON OM, so **SALON always comes first and stays small**: tracked above a lean classical "OM" (stacked) or before it, past a hairline (inline, "SALON | OM"). OM is outlined from Cormorant Garamond Light with the O opened to a true circle (unity). Drawn inline so it takes any ink.

- **Provide:** `variant` (`stacked` | `inline` | `om`), and `width` or `height`. Colour comes from CSS `color`: ivory on dark and film, ink on clay, forest for a single accent use.
- `draw` (stacked only) plays the hero intro: SALON rises in, then OM draws itself as a thin outline and fills in.
- Use `stacked` as the hero mark (min(58vw, 660px)) and in the footer, never below 200px wide. Use `inline` in the header (30px tall, 24px on phones). Use `om` for the favicon and very small marks.
- Never add rings, glows, outlines or gradients to the mark. Never put SALON after OM.
